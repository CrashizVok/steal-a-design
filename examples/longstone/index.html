01Chain of custody

A gap in the chain is a missing signature, not a disputed log.

Each handoff hashes the sensor payload against the carrier's key and writes the digest to the shipment. If a scan never arrives, the record shows a hole at that timestamp instead of smoothing it into an average over the leg.

02Envelope scoring

Scored against the product's own range, not a threshold for the fleet.

Vaccines, biologics and excipients each hold their own permitted band, per SKU and per route. An excursion on one lane does not inherit the tolerance of another, and the band travels with the lot rather than sitting in a spreadsheet beside it.

03Lot holds

A parcel that leaves its envelope is locked before the next scan.

The hold is written against the lot number, not the tracking number, so the receiving warehouse cannot book it into sellable stock. Release takes a quality signature and a reason code, both appended to the record.

04Audit export

One file a reviewer can read without asking you a question.

Audit packs leave as PDF/A-3 with the raw sensor payload embedded, so a reviewer opens a single file rather than a folder of CSVs and a login. The EPCIS event stream rides alongside for the systems that want it.

{
  "type": "ObjectEvent",
  "eventTime": "2026-11-04T04:12:07Z",
  "bizStep": "shipping",
  "disposition": "in_transit",
  "epcList": ["lot:PX-8841"],
  "readPoint": { "id": "loc:NL-RTM-04" },
  "sensor": {
    "minC": 2.4, "maxC": 8.1, "bandC": [2, 8],
